📚 项目简介
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
这是一个基于AI的智能学习管理平台，通过多Agent协作帮助你：
✓ 规划学习路径
✓ 管理学习任务
✓ 记录学习进度
✓ 生成知识测验
✓ 分析学习数据
✓ 提供智能建议

🎯 核心特色
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. AI智能助手
   - 规划助手：自动分解学习目标为可执行任务
   - 学习教练：提供学习方法和资源建议
   - 复盘分析师：深度分析学习数据，发现问题
   - 知识管理员：生成测验题，安排复习计划
   - 激励伙伴：保持学习动力和热情

2. 现代化设计
   - 清爽的蓝紫渐变配色
   - 流畅的动画效果
   - 完整的暗黑模式
   - 响应式布局

3. 技术优势
   - 全栈TypeScript，类型安全
   - React 18 + Vite 6，极速开发
   - Tailwind CSS，原子化样式
   - 本地SQLite，数据自主
   - 支持DeepSeek和OpenAI

4. 隐私保护
   - 数据存储在本地
   - API密钥自己管理
   - 仅本机访问
   - 不上传个人信息

🚀 快速开始
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
最简单的方式：

Windows用户：
  双击运行 quick-start.bat

Mac/Linux用户：
  chmod +x quick-start.sh
  ./quick-start.sh

手动安装：
  1. npm install
  2. 复制 .env-new.example 为 .env
  3. 编辑 .env，填入API密钥
  4. npm run db:migrate
  5. npm run dev

访问地址：
  前端：http://localhost:5173
  后端：http://127.0.0.1:5000

❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Q: 需要什么环境？
A: Node.js 20或更高版本

Q: API密钥从哪里获取？
A: DeepSeek: https://platform.deepseek.com/
   OpenAI: https://platform.openai.com/

Q: 数据存储在哪里？
A: 本地SQLite数据库（data/learning.db）

Q: 如何重置数据？
A: 删除 data/learning.db 后运行 npm run db:migrate

Q: 端口被占用怎么办？
A: 编辑 .env 文件，修改 PORT=5000 为其他端口

Q: AI功能不工作？
A: 检查.env中的API密钥，确保有网络和余额

Q: 支持多语言吗？
A: 当前仅中文，多语言支持在规划中

Q: 可以自定义主题吗？
A: 支持明/暗主题切换，自定义主题在规划中
